Computer science is the study of computation, algorithms, data structures,
software, and the principles used to design efficient computer systems.

An algorithm is a finite sequence of well-defined instructions used to solve
a problem. Different algorithms can solve the same problem with different
levels of efficiency. Algorithm analysis helps us understand the time and
space requirements of a solution.

Data compression is the process of representing information using fewer bits.
Lossless compression allows the original information to be reconstructed
exactly after decompression. LZ-78 is one example of a lossless compression
algorithm based on a dynamically constructed dictionary.

A dictionary stores patterns that have already appeared in the input.
When the compressor encounters a pattern that is already known, it can use
a dictionary index instead of storing the complete pattern again.

A larger dictionary can store more patterns.
A smaller dictionary uses less memory.
A dictionary that becomes full may need to be reset.
Resetting the dictionary allows the compressor to continue processing
new patterns without exceeding the selected dictionary limit.
